# VideoBrowse System - Complete Technical Documentation ## 🎯 Project Overview Project Name: VideoBrowse System (SLIITFLIX) Technology Stack: Spring Boot 3.2.6, Java 17, Maven, H2/MySQL, Thymeleaf, Bootstrap Architecture: MVC (Model-View-Controller) with Spring Security Purpose: A full-featured video streaming platform with user management, content management, and administrative capabilities --- ## 🏗️ Spring Boot Architecture Components ### 1. Controllers - The Traffic Directors What are Controllers? Controllers are the entry points of your application. They handle HTTP requests from users and coordinate between the frontend and backend services. How they work: - Receive HTTP requests (GET, POST, PUT, DELETE) - Validate input data - Call appropriate services - Return responses (HTML pages, JSON data, redirects) Example in our project: 

@Controller
@RequestMapping("/videos")
public class VideoController {
    @GetMapping("/upload")
    public String uploadForm() {
        return "videos/upload"; // Returns HTML template
    }
    
    @PostMapping("/upload")
    public String uploadVideo(@ModelAttribute VideoUploadRequest request) {
        videoService.uploadVideo(request); // Calls service
        return "redirect:/videos"; // Redirects user
    }
}
### 2. Entities - The Data Models What are Entities? Entities represent database tables as Java objects. They define the structure of your data and relationships between different data types. Key Features: - Map to database tables - Define relationships (One-to-Many, Many-to-One) - Include validation annotations - Handle data persistence Example in our project:

### 3. Repositories - The Data Access Layer What are Repositories? Repositories handle all database operations. They provide methods to save, find, update, and delete data without writing SQL queries. Types in our project: - JpaRepository: Provides basic CRUD operations - Custom Queries: For complex database operations Example: 

@Repository

### 4. Services - The Business Logic What are Services? Services contain the business logic of your application. They process data, implement business rules, and coordinate between different components. Responsibilities: - Business logic implementation - Data validation - Transaction management - Integration with multiple repositories Example: 

@Service
@Transactional

### 5. Security - The Protection Layer What is Spring Security? Spring Security handles authentication (who you are) and authorization (what you can do) in your application. Components: - Authentication: Login/logout functionality - Authorization: Role-based access control - Password Encryption: BCrypt hashing - Session Management: User sessions and remember-me Example: 

@Configuration
@EnableWebSecurity
public class SecurityConfig {
    @Bean
    public SecurityFilterChain filterChain(HttpSecurity http) {
        return http
            .authorizeHttpRequests(auth -> auth
                .requestMatchers("/admin/").hasRole("ADMIN")
                .requestMatchers("/profile/").authenticated()
                .anyRequest().permitAll()
            )
            .formLogin(form -> form
                .loginPage("/login")
                .defaultSuccessUrl("/")
            )
            .build();
    }
}

@Service
@Transactional
public class UserService {
    @Autowired
    private UserRepository userRepository;
    
    @Autowired
    private PasswordEncoder passwordEncoder;
    
    public User register(String username, String email, String password, boolean isAdmin) {
        User user = new User();
        user.setUsername(username);
        user.setEmail(email);
        user.setPassword(passwordEncoder.encode(password));
        
        if (isAdmin) {
            user.getRoles().add(Role.ROLE_ADMIN);
        } else {
            user.getRoles().add(Role.ROLE_USER);
        }
        
        return userRepository.save(user);
    }
}
Purpose: Implements user-related business logic and operations #### 5. UserRepository.java - Data Access Layer

@Configuration
@EnableWebSecurity
public class SecurityConfig {
    @Bean
    public SecurityFilterChain filterChain(HttpSecurity http) throws Exception {
        return http
            .authorizeHttpRequests(auth -> auth
                .requestMatchers("/admin/").hasRole("ADMIN")
                .requestMatchers("/profile/").authenticated()
                .requestMatchers("/videos/upload").authenticated()
                .anyRequest().permitAll()
            )
            .formLogin(form -> form
                .loginPage("/login")
                .defaultSuccessUrl("/")
                .failureUrl("/login?error=true")
            )
            .logout(logout -> logout
                .logoutUrl("/logout")
                .logoutSuccessUrl("/")
            )
            .build();
    }
}
